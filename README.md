# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 开盒核对

- 每款游戏先登记配件清单：配件名称、应有数量、缺件时的替代办法。
- 准备开局时在「开局前核对」逐项填写现场实有数量，不足的配件会标出缺口；存在未核对项或未解决的缺口时，「开始开局」按钮保持禁用并说明原因。
- 缺口可以通过补足数量或确认替代办法（可一键采用登记的替代办法）解决，已核对的内容会保留，不用重填。
- 开局后再发现缺件，在「局中补记」里记录当时的缺口和替代方案，继续补记不影响本局。
- 每款游戏的核对结果分开保存，数据存在浏览器 localStorage，重开页面可接着上次继续；下次开桌前可用「重新核对」清空本次填写重新开始。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
