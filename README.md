# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 开盒核对

详情页的「开盒核对」标签页用来解决"收盒后配件常缺、开桌前才发现凑不齐"的问题：

- **配件登记**：每款游戏先登记配件名称、应有数量和替代办法。
- **开局前核对**：逐项填写现场实有数量，不足的配件会列出缺口；数量未填完或缺口未处理时，「开局」按钮保持禁用。缺口可以补足实有数量，也可以按登记的替代办法点「采用替代」确认；已核对过的项会自动保存，不用重填。
- **对局中补记**：开局后又发现缺少时，选择配件补记现场数量和本局替代方案，缺口与替代方案会按当时情况快照保存，继续补记不影响本局进行。
- **收盒**：结束本局后清空本次核对数量，下次开盒重新逐项核对；历史缺少记录保留，方便日后补齐配件。

每款游戏的配件登记、核对进度和缺少记录都分开保存在浏览器 localStorage，页面重开后可以接着上次继续。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
